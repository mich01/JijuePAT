This is a Psychometric Assessment Toolkit P.A.T developed back in 2017/8. It uses different multimedia, like Images and Videos, to assess one's psychological Traits and proclivities.
Though poorly written and not supported. You are welcome to copy, try it out, and improve on it. Have fun!

For the UI you will also need to add/Import the bower_components folder
